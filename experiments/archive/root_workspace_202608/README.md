# Root Workspace Utility Snapshot

This directory preserves standalone analysis, calibration, notebook-generation,
fidelity-debugging, and policy-check scripts that were retained at the research
workspace root in August 2026. `root_experiments/` contains the accompanying
energy-calibration and learned-baseline runners.

These are historical utilities, not canonical package entry points. They keep
their original paths and assumptions for provenance. Use the maintained
top-level experiment scripts for new runs.
