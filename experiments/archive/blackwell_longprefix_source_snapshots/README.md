# Blackwell Long-Prefix Source Snapshots

This directory preserves the six source snapshots captured with the July 2026
Blackwell long-prefix campaigns. Directory names retain the originating model
group so run scripts and manifests can be matched without assuming all groups
used an identical source revision.

Generated caches were excluded. Source, tests, configuration, launch scripts,
and analysis code are otherwise retained as captured. Use
`results/blackwell_longprefix_hf/` for measurements and the canonical source
tree for new development.
