# P100 Source Snapshots

These source trees retain two earlier P100 package stages plus the available
phase-1/2/3 learned-baseline and Blackwell-semantic runners. They supplement the
final expanded P100 package in `reproduction_packages/p100_hf/` and preserve
version differences found in historical commands.

Use these snapshots only with their matching manifests. They do not supersede
the maintained implementation.
