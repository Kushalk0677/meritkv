# Learned Admission Baseline

This tree retains every available raw and derived file from the learned-policy
campaign. Four model families completed their recorded cells. The Phi-3 phase
stopped during model loading because of GPU OOM, so no Phi-3 measurement is
invented or reconstructed.

The `phase3_partial/` name records that execution boundary; it does not mean
that completed-model raw files were sampled or pruned. Consult the local plans,
commands, logs, per-cell outputs, and summaries before aggregating results.
