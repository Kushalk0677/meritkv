# Controlled T4/P100 Results

This directory contains the complete retained controlled benchmark: 898
measured JSON cells, manifests, and aggregate CSVs across five models, ten
datasets, three prompt modes, and seeds 42, 123, and 456. The manifest records
450 P100 and 448 T4 cells; two T4 Phi-3 templated cells were unavailable.

Use `summary_by_engine.csv` for the primary policy aggregate and the raw JSON
tree for per-cell auditing. Engine IDs follow the mapping in the repository
README. No missing cell has been inferred or synthesized.
