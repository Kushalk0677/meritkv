# Unique External-Handoff Records

This snapshot contains only file contents that were absent from the canonical
repository when the August 2026 cleanup audited the Blackwell, P100, incoming,
and transfer workspaces. Original relative paths are preserved below a
source-directory name.

After historical archives were expanded, byte-identical snapshot copies were
removed. `DEDUPLICATION_MAP.csv` records every removed path, its preserved
repository location, SHA-256, and byte count. The remaining files are unique
raw records, manifests, reports, environment captures, dry-run outputs, and
package receipts; they must not override current paper-facing aggregates.
