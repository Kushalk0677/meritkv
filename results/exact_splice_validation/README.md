# Explicit-State Continuation Validation

These JSON reports compare explicit cache-state continuation with the
equivalent cached reference under the package-recorded precision, attention
implementation, masks, and positions. `EXACT_SPLICE_VALIDATION.md` defines the
comparison rules and results.

The complete executable Colab package, environment record, logs, and downloaded
result archive are in `reproduction_packages/colab/exact_splice_validation/`.
This direct-equivalence check is distinct from crop-and-replay ROUGE-L.
