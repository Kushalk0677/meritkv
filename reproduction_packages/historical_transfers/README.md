# Expanded Historical Transfers

Each directory is the safe expansion of a descriptively named archive in
`../archives/historical/`. These packages preserve early P100 controlled and
learned-admission results, source stages, Blackwell semantic runners, and the
partial pre-Phi-3-OOM learned campaign.

The directory also includes expanded robust-policy source/result snapshots that
were packaged inside historical workspaces. Package-local READMEs and manifests
retain their historical terminology. They are provenance, not a second
paper-facing result set. The canonical learned and controlled results remain
under `results/`.
